# 📱 Telegram-квест: «Цифровой этикет и последствия кибербуллинга»

Интерактивная текстовая игра (Telegram-бот), созданная для повышения осведомленности о цифровой гигиене, кибербуллинге и ответственности за свои действия в интернете.

> *"Следите за тем, как вы общаетесь в сети. Потому что как и здесь, там нет кнопки «назад»."*

## 📖 О проекте

В основу сюжета легла типичная для подростковой среды ситуация: в школьном паблике «Подслушано» публикуется компрометирующее видео с одной из учениц. 
Игрок выступает в роли стороннего наблюдателя, чьи действия (или бездействие) напрямую влияют на судьбу героини и развитие конфликта. 

**Цель игры** — наглядно показать, как быстро распространяется информация в сети, как эффект толпы усугубляет травлю, и почему важно иметь смелость остановить кибербуллинг.

## ✨ Ключевые особенности

- **Разветвленный сюжет:** Десятки вариантов развития событий. Каждое решение имеет вес и направляет игрока по одной из множества сюжетных веток.
- **Моральный выбор:** Игрок решает: присоединиться к насмешкам, проигнорировать ситуацию или попытаться защитить жертву.
- **Система последствий:** 3 прописанных финала (от трагического до благополучного), зависящих от действий игрока.
- **Сохранение прогресса:** Бот автоматически запоминает, на каком шаге остановился игрок, используя базу данных SQLite.

## 🛠 Технологии

- **Язык программирования:** Python 3.x
- **Библиотека для работы с API:** `pyTelegramBotAPI` (`telebot`)
- **База данных:** `sqlite3` (Встроенная, не требует отдельного сервера)

## 📂 Структура проекта

- `bot.py` — Главный файл с логикой Telegram-бота, обработчиками сообщений и кнопок.
- `questions.py` — Файл с контентом игры: содержит словари `QUEST_DATA` (сценарий квеста) и `RESULTS_DATA` (финалы игры).
- `migrate.py` — Скрипт миграции. Инициализирует и переносит текстовые данные в базу данных `game_progress.db`.
- `game_progress.db` — (Генерируется автоматически) База данных SQLite, хранящая логику вопросов и прогресс пользователей.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ShirinkinTima/tg-bot-game_digital-etiquette.git
cd tg-bot-game_digital-etiquette
```

### 2. Настройка виртуального окружения (рекомендуется)
```bash
python -m venv venv
# Активация для Windows:
venv\Scripts\activate
# Активация для macOS/Linux:
source venv/bin/activate
```

### 3. Установка зависимостей
Убедитесь, что у вас установлена библиотека для работы с Telegram API:
```bash
pip install pyTelegramBotAPI
```

### 4. Настройка токена бота
Откройте файл `bot.py` и найдите строку:
```python
TOKEN = 'ВАШ_ТОКЕН_ОТ_BOTFATHER'
```
*(Рекомендуется в будущем вынести токен в переменные окружения `.env` для безопасности)*.

### 5. Инициализация базы данных
Перед первым запуском бота необходимо создать базу данных и загрузить в неё сценарий. Выполните скрипт миграции:
```bash
python migrate.py
```
*Вы должны увидеть сообщение: `--- Миграция успешно завершена! ---`*

### 6. Запуск бота
```bash
python bot.py
```
После появления надписи "Бот запущен..." перейдите в Telegram, найдите своего бота и отправьте команду `/start`.

## 🎮 Команды бота

- `/start` — Начать игру / получить приветственное сообщение.
- `/stop` — Сбросить текущий прогресс и начать историю с чистого листа.
